# YouTube uploads

One entry per video: paste the title, description and tags, upload the captions file under
Subtitles (English), and set the thumbnail. Chapters are already in each description: YouTube
reads them from the timestamps (the first at 0:00, each 10 seconds or longer).

All videos: 1920 × 1080 (the vertical promo 1080 × 1920), 30 fps, H.264 and AAC, loudness about
−14 LUFS. Put the tutorials in one playlist, in order, so each video's "Up next" card matches.
