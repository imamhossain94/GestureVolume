# Store art and videos

Everything here is drawn from the app's own code (its Compose screens, AGSL shaders, vector
drawables and strings) by the renderer in [`tool/store`](../tool/store), not captured on a phone.
Compare a few screens with a real device before you publish.

## Google Play

| File | Size | Where it goes |

Play's promo video is a YouTube link: upload `video/promo-1080p.mp4`, then paste its URL into Main
store listing › Video. Play then shows the feature graphic as the video's cover: cropped to 16:9,
which takes 68 px off each side, with a play button over the middle. So the words and the sliders
sit inside that crop, in its left and right thirds, and the middle is left clear. The promo's
thumbnail is the same layout at 16:9.

## YouTube

| File | What |
|---|---|
| `video/promo-1080p.mp4` | The promo, 0:30, 1920 × 1080, cut to its music, with a line from the narrator in each section. |
| `video/promo-vertical.mp4` | The same, 1080 × 1920, for Shorts. |
| `video/promo-thumbnail.png` | Its thumbnail, 1280 × 720. |
| `tutorials/NN-name.mp4` | One narrated tutorial per feature, 1920 × 1080, in series order. |
| `tutorials/NN-name.srt` | English subtitles for each: the narrator's words, which are the on-screen captions, timed on the voice. |
| `tutorials/NN-name.json` | Each tutorial's steps, chapters, subtitles and narration timings. |
| `tutorials/thumbnails/NN-name.png` | Thumbnails, 1280 × 720. |
| `tutorials/youtube.md` | Titles, descriptions with chapters, and tags for each video, and how the narration is made. |

The videos are narrated, over music and sound effects, mixed to −14 LUFS with true peaks under
−1.5 dBTP. The narrator is a synthetic voice, Kokoro-82M's af_bella at speed 1.0, made on this
machine by `tool/store/vo.py` (the channel's Sonary tutorials use the same voice). In a tutorial it
reads the title card, every step's title and text as they stand beside the phone, and the "Up
next" card; a step whose line is longer than its scripted time holds its end until the line is
done. The music is generated by `tool/store/audio.py` and ducked under the voice; the tick on each
volume step is the app's own `res/raw/slider_tick.wav`.

## Making it again

See the commands at the top of each script in [`tool/store`](../tool/store): `render-graphics.mjs`
and `finish.py` for Play, `render.mjs` for the videos, `render-thumbs.mjs`, `youtube.mjs` and
`gallery.mjs` for the rest. Shaders, drawables and strings are read from the app, so after a change
to the app, a re-run picks it up.

To check one screen against the app after a change, render its test page on its own, for example
`node render.mjs still test_fills check.png` for every Quick slider fill; the pages are
`tool/store/scenes/test_*.html`, and `tool/store/dev` has the debugging helpers.

### The narrator

`vo.py` runs Kokoro-82M (Apache-2.0) locally with kokoro-onnx 0.6 or later. The model (about
350 MB) is not in this repo. To set it up on a new machine:

```sh
python3.12 -m venv ~/.venvs/kokoro
~/.venvs/kokoro/bin/pip install "kokoro-onnx>=0.6" soundfile numpy
# kokoro-v1.0.onnx and voices-v1.0.bin, from kokoro-onnx's GitHub releases, into one folder, then:
export VO_PYTHON=~/.venvs/kokoro/bin/python VO_MODEL_DIR=/path/to/that/folder
```

On this machine nothing needs setting: both default to the copies Sonary's video tools keep in
`~/FlutterProjects/audio_ai/tool/store/video/.cache`. Clips are cached in `tool/store/build/vo/`,
so only a line whose words changed is spoken again. Check how a word will be said with
`$VO_PYTHON vo.py phonemes "Gesture Volume"`; `SAY` and `PRONOUNCE` in `vo.py` fix one that reads
badly (none needed so far).

### One video again

From `tool/store`, once per checkout: `npm install`, `npx playwright install --only-shell chromium`
(if Playwright asks for its browser), `python3 vd2svg.py --all ../../app/src/main/res/drawable
build/drawable` and `python3 extract_shaders.py`. Then, for a tutorial (its id is in `SERIES` in
`kit/tutorial.js`, its script in `kit/tutorials/<id>.js`) or the promo:

```sh
node render.mjs video tutorial ../../store/tutorials/09-visibility.mp4 --query id=visibility --crf 20 --tune animation
node render.mjs video promo ../../store/video/promo-1080p.mp4
node render.mjs video promo ../../store/video/promo-vertical.mp4 --query v=1
node youtube.mjs                     # the new chapters and lengths into youtube.md
```

`render.mjs` asks the video for its lines, has `vo.py` speak them, times the steps to the voice,
renders, mixes and writes the `.srt` and `.json` beside the `.mp4`. A new step in a tutorial is
narrated like the others with nothing else to do; its thumbnail keeps the scripted timing, so
`THUMB.t` still points at the same moment. `node render.mjs still tutorial check.png --t 40 --query
id=visibility` shows one moment of the narrated video; `node render.mjs remix tutorial
../../store/tutorials/09-visibility.mp4 --query id=visibility` puts new sound under a finished
video without rendering its frames again; `--novo` leaves the narrator out.
