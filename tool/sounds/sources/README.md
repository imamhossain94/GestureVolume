# Recorded sources

The few step sounds that are recordings rather than code. Each is public domain, so nothing needs
crediting in the app; the source is kept here so anyone can check it.

- `meow.wav` — the second meow of "Small mewing of a cat", sound #0098 of BigSoundBank
  (https://bigsoundbank.com/small-mewing-of-a-cat-s0098.html), recorded by Joseph Sardin and
  dedicated to the public domain under CC0. Cut from 1.06 s for 0.71 s of the downloaded file and
  resampled to 44.1 kHz, nothing else. `step_sounds.py meow` makes `res/raw/step_meow.wav` from it.
